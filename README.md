# Webnion AI Agent

The AI service behind the Webnion website: a site assistant that answers visitors' questions from the site's content and takes
inquiries, and a blog writer that drafts posts with pictures for the team to review. Python, FastAPI, LangChain, LangGraph,
LangSmith and Pinecone, deployed on Vercel. Any chat, picture or embedding provider can be used: the provider, model name and
API key are set in the Webnion admin panel.

See [PLAN.md](PLAN.md) for the design, the decisions behind it and the build phases.
